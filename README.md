# Intelligent-bus-stop-platform
# 智能公交站台监测与控制系统（STM32版）
基于STM32单片机的多功能智能公交站台系统，完整实现公交到站显示、环境监测、智能照明、蓝牙无线通信等功能，适配课程设计/实训项目。

## 项目核心
- **主控芯片**：STM32F103系列（HAL库开发，兼容CubeMX配置）
- **开发环境**：STM32CubeIDE / Keil MDK-ARM
- **工程结构**：标准STM32CubeMX生成目录，可直接打开编译

## 功能实现
### 基础功能
1.  **公交到站OLED显示**：3路公交倒计时显示，<3分钟声光提醒，按键/远程可调整时间
2.  **实时时钟**：DS1302模块驱动，OLED显示当前时间，掉电走时
3.  **环境监测**：DHT11温湿度+光敏电阻光照检测，每10秒刷新显示
4.  **智能照明**：手动按键开关+自动感光调光，PWM无级调节亮度

### 进阶功能
1.  **蓝牙无线通信**：HC-05/HC-06串口通信，手机/电脑远程查询公交信息、接收到站提醒
2.  **求助报警**：物理按键触发蜂鸣器，蓝牙同步发送求助信号给管理员
3.  **远程配置**：管理员通过蓝牙远程修改公交到站时间

## 硬件清单
- STM32F103C8T6核心板
- OLED I2C显示屏（128×64）
- DS1302实时时钟模块
- DHT11温湿度传感器
- 光敏电阻模块
- LED照明灯+限流电阻
- 独立按键、有源蜂鸣器
- HC-05/HC-06蓝牙模块
- 杜邦线、电源模块

## 使用说明
1.  用STM32CubeIDE/Keil打开工程，直接编译下载
2.  按原理图完成硬件接线
3.  上电运行，OLED显示所有功能数据
4.  蓝牙连接手机APP，实现远程监控与控制
